## 🌟 Features

* **Multi-Modal Communication:** Connect via Secure Text, Voice Chat, or Video Call.
* **Privacy First:** "Don’t worry, the information you give is protected by privacy laws and cannot be used against you."
* **Responsive Design:** Fully optimized for desktop, tablets, and mobile devices with touch-friendly controls.
* **Real-Time Connection:** Powered by the Agora RTC SDK for low-latency communication.

## 🛠️ Tech Stack

* **Web-Technologies:** HTML5, CSS3, Vanilla JavaScript, Node.js
* **Real-Time Media:** Agora RTC SDK (v4.18.2)
* **Icons:** FontAwesome
* **Fonts:** Quicksand & Pacifico (Google Fonts)

## 🛠️ Prerequisites

Before you begin, ensure you have the following installed:
* **Node.js** (v14 or higher) & **npm**
* **Gitbash** (for cloning)

## 🚀 How to Run

1.  **Clone the repository**
    ```bash
    git clone https://github.com/ClauDevy/anchor-app.git
    cd anchor-app
    ```

2.  **Install Dependencies**
    This downloads the required packages (Express, etc.) listed in `package.json`.
    ```bash
    npm install
    ```

3.  **Start the Server**
    Run the application locally.
    ```bash
    node server.js
    ```

4.  **Open in Browser**
    You will see a message in your terminal: `Anchor Server running at http://localhost:3000`.
    Open your web browser and go to:
    ```
    http://localhost:3000
    ```
